# Screenshot capture manifest

Save authentic, legible PNG captures from the indicated application in this folder. Use the numbered sequence in `../docs/LAB-GUIDE.md`; the requested terminal evidence should show the real PowerShell or Ubuntu terminal window, never the assistant UI. Recommended capture resolution: 1920×1080 or larger.

The current build environment did not expose a terminal application window to the screen-capture interface, so screenshots cannot honestly be pre-populated from command output here. Capture them while running the guided labs on your own desktop.
